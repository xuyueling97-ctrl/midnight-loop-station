# 午夜零点：无限循环车站

一款像素风悬疑解谜网页小游戏。你在午夜醒来，被困在一座时钟永远指向 00:00 的车站。每当列车进站，时间便会重置——但有些东西，不会随着循环消失。

**版本**：V0.1 · **类型**：点击探索 / 时间循环 / 多结局 · **技术**：原生 HTML + CSS + JavaScript（零依赖）

**在线试玩（GitHub Pages）**：https://xuyueling97-ctrl.github.io/midnight-loop-station/

---

## 运行方式

**双击 `index.html` 即可游玩**，推荐使用 Chrome / Edge 浏览器。

- 无需安装、无需构建、无需联网、无任何外部 API。
- 支持电脑端鼠标键盘，兼容手机触屏。
- 进度自动保存在浏览器 `localStorage`，可随时"继续游戏"。

## 操作说明

| 操作 | 方式 |
|---|---|
| 调查 / 对话 | 点击场景中的发光热点（悬停显示名称） |
| 切换区域 | 底部导航：站台 / 候车室 / 售票处 / 失物处 |
| 快捷键 | `1-4` 切场景，`B` 背包，`J` 线索，`Esc` 关闭面板 |
| 背包 / 线索 / 菜单 | 右上角按钮 |
| 声音开关 | 右上角 🔊 按钮 |
| 触屏 | 直接点按热点与底部大按钮 |

## 玩法机制

- **时间循环**：每轮 5 分钟。列车进站后若不做出选择，时间归零将进入下一夜。
- **跨轮记忆**：线索记录与"★ 记忆物品"跨轮保留；普通道具会被重置。部分人与事，也会记住你做过什么。
- **阅读不赶时间**：对话框、背包、线索、菜单打开时计时暂停。
- **多结局**：普通结局、真结局，以及一个隐藏结局。真结局之后，故事并未真正结束……
- **目标提示**：HUD 会显示当前建议目标，卡关时可先查看线索面板。

## 文件结构

```
index.html            入口页面（标题 / 游戏 / 帮助）
styles.css            像素风 UI、响应式布局、人物剪影与氛围动画
scripts/
  data.js             场景 / 热点 / 道具 / 线索 / 结局数据
  engine.js           游戏逻辑引擎（交互、循环、记忆、结局判定、存档）
  game.js             UI 渲染与输入、计时、面板、数字键盘
  audio.js            WebAudio 合成音效与氛围音乐（无音频文件依赖）
assets/               场景背景与人物立绘（WebP）+ bgm.mp3 配乐
tests/
  engine.test.js      引擎自动化测试（12 项）
  ui-smoke.js         资源引用与启动冒烟测试（3 项）
  browser-e2e.js      真浏览器三结局 E2E（Edge headless + CDP）
DEV_REPORT.md         开发与测试报告
AUDIT_REPORT.md       早期独立审计报告（历史存档）
```

> 注：`backup/`（原始工程备份）、`tests/artifacts/`（E2E 截图）为本地生成内容，已通过 `.gitignore` 排除，不随仓库分发；运行 E2E 后会在本地重新生成截图。

## 实现说明

- 画面：AI 生成的像素风背景与人物立绘（对话框头像）+ CSS 人物剪影 + 暗角与呼吸动画。
- 声音：`assets/bgm.mp3` 生成配乐 + WebAudio 实时合成（风声、灯管微鸣、事件音效；配乐播放失败自动回退合成旋律），首次点击后启用，右上角可静音。
- 存档：`localStorage` 自动存档 + 菜单手动存读档；损坏存档自动清洗。
- 剧情伏笔与谜题线索相互咬合，建议亲自探索，不必急于查攻略。
